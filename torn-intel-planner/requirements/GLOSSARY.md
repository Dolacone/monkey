# 用語

| 用語 | 意思 |
|---|---|
| 優先組合 | 一組「國家 + 物品」，例如 Japan Xanax |
| 航班 | 一趟來回：出發（LEAVE）、在國外購買（BUY）、回到 Torn（BACK） |
| 立即航班 | 買國外目前庫存、不等補貨的航班，沒有補貨時間 |
| 排程補丁 | 替換網站排程函式的補丁 |
| 可飛判斷補丁 | 取得網站航班限制檢查的補丁 |
| 目的地篩選補丁 | 替換網站目的地篩選的補丁 |
| 網站計畫 | torn-intel Departure Planner 排出的當天行程（時間軸與 Trips） |
| leave DM | 出發前的 Discord 提醒，即使用者說的 FLIGHT DM |
| restock DM | 補貨時的 Discord 提醒 |
| 睡眠時段 | 網站 schedule 裡的 afk 時段，時間軸上顯示為 Asleep / away |
| Xanax 時間 | 目前藥物冷卻（drug cooldown）結束的時間 |
| priority 模式 | 勾選結果由優先順序自動決定 |
| manual 模式 | 勾選結果由使用者手動決定 |
