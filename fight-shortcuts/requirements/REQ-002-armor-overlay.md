# REQ-002 — 護甲覆蓋層

## 情境

> 攻擊頁本身不會直接顯示對手穿著的護甲部位與類型，需要在對手模型上疊加一層資訊，並依護甲類型提示應優先使用哪種武器。

## 行為

### 偵測與重試

1. 攻擊頁載入時開始偵測對手護甲，最多重試 5 次，每次間隔 500ms。
2. 對手玩家容器 (`.player___vjxP2` 內含 `#weapon_main.defender___l1ETt`) 尚未出現時，視為一次失敗並重試。
3. 對手容器已出現、但護甲區塊 (`map area`) 尚未出現時，視為一次失敗並重試。
4. 重試次數用盡後護甲區塊仍不存在，顯示「No armor」，並改為監聽對手模型視窗的 DOM 變化，等待護甲區塊之後才出現時，重新渲染真實護甲清單。

### 護甲清單

5. 讀取對手 `<area>` 元素：`alt` 為身體部位，`title` 為護甲名稱。
6. 依身體部位 (`alt`) 去重，同一部位只顯示一次。
7. 找不到任何護甲區塊時顯示「No armor」。

### 護甲類型與武器提示

8. 依第一個符合的護甲名稱判斷護甲類型：名稱包含 assault / riot / vanguard（不分大小寫）之一。
9. 護甲類型為 assault 時，攻擊方主武器與副武器欄位加上藍色內框提示 (`inset 0 0 0 4px rgb(0, 120, 255)`)。
10. 護甲類型為 riot 時，攻擊方近戰武器欄位加上同樣的藍色內框提示。
11. 護甲類型為 vanguard 時，攻擊方臨時武器欄位加上同樣的藍色內框提示。
12. 護甲類型無法判斷時，攻擊方所有武器欄位不加提示框。
13. 每次重新渲染護甲清單前，先清除攻擊方武器欄位上舊的提示框。

### 覆蓋層外觀

14. 護甲清單顯示在 `#armor-info`，以 `prependTo` 插入對手模型視窗 (`.playerWindow___sDs7q`)。
15. `#armor-info` 使用絕對定位覆蓋在模型視窗左上角、寬度 100%、半透明深色背景，且不擋滑鼠事件 (`pointer-events: none`)。
