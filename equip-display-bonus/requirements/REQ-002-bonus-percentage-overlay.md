# REQ-002 — 裝備加成百分比疊加顯示

## 情境

> 當頁面中的裝備帶有 weapon bonus 效果的時候(顯示於裝備右上角的 icon),把 `XX%` 用類似 tooltip 的顯示方式,永久顯示在那個裝備的左上角。如果裝備有多個 bonus,則以換行顯示。武器與盔甲的加成都要顯示。

## 行為

1. 當一個裝備(武器或盔甲)帶有一個或多個加成(weapon bonus 或 armor bonus,不含未附加的空白加成格)時,在該裝備圖示的左上角疊加顯示對應的加成名稱與百分比。
2. 顯示格式為「{加成名稱} {數字}%」,例如 `Warlord 20%`。
3. 同一裝備有多個加成時,依序垂直換行顯示,例如:
   ```
   Warlord 20%
   Expose 16%
   ```
4. 疊加顯示為永久顯示,不需滑鼠 hover 觸發,且不影響頁面原生 tooltip 的行為。
5. 空白加成格(裝備仍有加成欄位但未附加任何加成)不顯示疊加文字。
6. 每個加成固定佔一行,文字寬度可超出裝備圖示原本的格子範圍,不因為圖示較窄而把單一加成折成兩行。
