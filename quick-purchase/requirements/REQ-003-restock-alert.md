# REQ-003 — 目標商品補貨提醒

## 情境

> 目標商品缺貨時，使用者要在補貨的當下馬上知道；頁面一載入目標商品就有庫存時，也要馬上知道。其他玩家買走造成的庫存減少不算補貨，不要提醒。提醒方式比照 crime-pickpocket：頁面背景變紅、播放提示音，另外訊息列變綠。

## 行為

1. 頁面上目標商品的 stock 從 0 變成大於 0 時，觸發補貨提醒。
2. stock 減少、或從一個大於 0 的數字變成另一個大於 0 的數字時，不觸發。
3. 腳本第一次讀到目標商品的 stock 大於 0 時，觸發補貨提醒。
   - 例如：頁面載入時已有庫存。
   - 第一次讀到 0 時不觸發。
4. 觸發時同時做三件事：訊息列背景變綠、整頁背景變紅、播放一次與 crime-pickpocket 相同的提示音。
5. 觸發後按下確認框的 Yes 時，訊息列和整頁背景恢復原本的顏色。
6. 恢復之後，目標商品再次從 0 回升時，再次觸發。
7. 不論 stock 變動來自即時推送或頁面重新抓取，只要頁面上的 stock 數字從 0 變成大於 0 就觸發。
